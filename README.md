# ⚡ Grid Demand Balancer

Demand-response signals and peak-shaving recommendations for facilities and aggregators. Part of the **Zion Energy & Facilities AI Suite (Batch 72)**.

## What it does
- Predicts peak events and recommends load-shed/shift actions
- Coordinates HVAC, EV chargers, batteries and process loads
- Automates demand-response program participation (utility & ISO signals)
- Quantifies demand-charge and DR revenue savings

## Key features
- Real-time dispatch optimization with comfort/process constraints
- Integrates forecasts from [Energy Consumption Forecaster](https://github.com/Zion-support/energy-consumption-forecaster)
- Uses solar/storage models from [Solar ROI Optimizer](https://github.com/Zion-support/solar-roi-optimizer)
- OpenADR / Modbus / BACnet connectors
